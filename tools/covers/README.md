# 프로젝트 카드 커버 템플릿

메인 페이지 프로젝트 카드(`components/Projects.tsx`) 상단에 들어가는 1280×640 커버를
HTML 로 짜고 캡처한다. 이미지 편집기 대신 코드로 두는 이유는 세 가지다.

- 배경색·폰트가 `app/globals.css` 토큰과 정확히 같다
- 문구를 고칠 때 이미지를 다시 만들 필요가 없다 — 캡처만 다시 뜬다
- 안전 영역(아래)을 눈대중이 아니라 규칙으로 지킨다

## 만들기

```bash
cd tools/covers
./capture.sh            # 전체
./capture.sh sodam      # 하나만
```

`public/covers/<html 파일명>.png` 가 나온다. `lib/profile.ts` 의 `thumbnail` 에 연결한다.

파일명은 보통 프로젝트 slug 를 쓰지만, **이미 배포한 커버의 그림을 갈아끼울 때는
파일명도 함께 바꾼다.** 경로가 같으면 브라우저가 옛 그림을 계속 쓴다. 그래서
`samsung-medison` 은 `samsung-medison-v2` 로 두었다. html 이름을 바꾸면 출력 이름도
따라 바뀌므로 `capture.sh` 를 다시 돌려도 옛 이름이 되살아나지 않는다.
(`thumbnail: "/covers/x.png?v=2"` 같은 쿼리는 쓸 수 없다 — Next 이미지 최적화가 400 을 낸다.)

별도 설치 없이 로컬 Chrome 의 headless 모드를 쓴다. 2x(2560×1280)로 찍고 1280 폭으로
줄인다 — 다운샘플링이 1x 렌더보다 선명하다.

## 안전 영역

카드 UI 가 커버 위에 겹쳐 그리는 자리가 두 군데 있다. 여기에는 아무것도 두지 않는다.

| 자리 | 크기 | 무엇이 덮나 |
| --- | --- | --- |
| 우하단 | 110×110 | `→` 원형 배지 (상시) |
| 정중앙 | 460×110 | "자세히 보기" 알약 (hover 시) |

확인하려면 `.cover` 에 `guides` 클래스를 붙인다 — 두 영역이 빨간 점선으로 보인다.
카드는 hover 시 `scale-[1.02]` 가 걸려 가장자리가 조금 더 잘리므로 바깥 5% 도 비워 둔다.

## 크기의 기준

커버는 카드에서 **약 500px 폭으로 줄어 보인다.** 화면에 뜨는 크기는 여기 값의 0.39배다.
글자든 목업이든 1280 화면에서 적당해 보이는 크기는 카드에서 대개 절반도 안 되게 작다.

- `.desc` 25px → 카드에서 10px. 이보다 작게 잡지 않는다
- `.title` 58px → 카드에서 23px

스크린샷 안 UI 글씨는 이 축소 때문에 **어떻게 해도 완전히 읽히지는 않는다.** 원본을
통째로 넣으면 회색 덩어리로 뭉개지므로, `.shot` 의 `--zoom` 으로 확대해 일부만 크게
보여준다. 전체를 담는 것보다 "무슨 화면인지" 형태가 살아나는 쪽이 낫다.

## 고치기

- **문구** — 각 html 의 `.eyebrow` / `.title` / `.desc`. 줄바꿈은 `<br>` 로 직접 끊는다.
  자동 줄바꿈에 맡기면 마지막 한 글자만 넘어가는 모양이 자주 나온다.
  카피 폭은 512px — 25px 기준 한 줄에 19자 안팎이 한계다.
  `.desc b` 는 문장에서 한 군데만 쓴다.
- **스크린샷** — `img` 의 `src` 를 바꾸고, 그 커버의 `.shot` 에서 확대를 맞춘다.

  ```css
  .shot {
    --zoom: 1.5;        /* 확대 배율 — 1 이면 폭에 맞춰 그대로 */
    --focus: top left;  /* 확대 기준점. 잘려서 안 될 정보가 있는 쪽으로 */
  }
  ```

  왼쪽에 라벨이 있는 폼 화면은 `top left`, 가운데가 중요하면 `top center` 를 쓴다.
  노트북·모니터에는 가로 비율(16:10 안팎) 캡처가 맞다 — 세로로 긴 캡처는 위쪽만 남는다.
- **목업 위치** — 무대보다 목업이 넓어 가장자리가 잘릴 때는 해당 html 에서
  `.laptop { transform: translateX(...) }` 또는 `.phones { transform: ... }` 로 당긴다.
- **배치** — `.cover` 에 `flip` 을 붙이면 목업이 왼쪽으로 간다. 지금은 카드 순서대로
  좌우가 번갈아 오도록 맞춰 뒀다.
- **배경색** — 각 html 의 `<style>` 안 `.cover { background }` 한 줄.

## 남은 것

`samsung-medison` 커버의 초음파 영상은 **프로젝트에서 다룬 원본 데이터가 아니라
회맹부 해부를 보여주는 참고 이미지**다(`public/samsung-medison/ref-ileocecal.png`).
원본 영상의 공개 가능 여부가 확정되면 `img` 의 `src` 만 바꾸면 된다.

커버에는 출처를 적을 자리가 없으니, 상세 페이지에서 참고 이미지를 함께 쓸 때는
`overviewFiguresNote` 로 성격을 반드시 밝힌다.
