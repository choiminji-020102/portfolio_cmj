## 1. 서비스를 혼자 끝까지 만듭니다

월간지 출판사의 구독관리 시스템을 9개월간 단독으로 기획·설계·개발·배포했고, 지금은 유지보수
계약으로 실서비스를 운영하고 있습니다. 엑셀로 관리되던 정기구독 3,200건을 시스템으로 옮겨 매월
발송 명단을 버튼 한 번으로 생성하게 만들었고, 정기구독·단품·VIP로 갈라져 있던 세 발송 흐름을
하나의 출력 구조로 통합하는 그룹화 알고리즘을 설계해 합포장 누락과 중복 발송을 없앴습니다.
13개 도메인 모델과 20개 API 라우터 전체에 소프트 삭제와 감사 로그를 적용했고, Cafe24 주문
연동에는 embed 조회를 적용해 100건 처리 시 수백 회이던 API 호출을 1회로 줄였습니다.

요구사항을 듣고, 도메인 규칙을 정의하고, 스키마를 짜고, 화면까지 만들어 담당자가 매일 쓰게
만드는 전 구간을 혼자 해냈습니다.

## 2. 모델보다 데이터를 먼저 의심합니다

삼성메디슨 AI Vision 그룹에서 6개월간 하복부 초음파 영상의 다중 구조물 검출을 맡았습니다.
학습을 반복해도 성능이 오르지 않자 조정과 결과 사이에 일관된 상관이 없다는 점을 근거로 병목이
모델이 아니라 정답 데이터에 있다는 가설을 세웠고, 사내 임상의와 원본 영상·레이블을 함께 검토해
GT 마스크의 경계 과다 문제를 확인·보고했습니다. 지표만으로는 드러나지 않던 클래스 인덱스
불일치와 좌표계 오류 2건도 직접 만든 검증 도구(정규화 레이블 역산 렌더링, GT/예측 병렬 비교)로
찾아냈습니다.

모델 선정은 논문 FPS가 아니라 실측값(CPU ONNX 86ms vs TensorRT 1.2ms)으로 후보 6종을 비교해
결정했고, 채택 후 AGPL-3.0 라이선스로 상용 의료기기 탑재가 불가함을 규명해 함께 보고했습니다.
영상 87개를 약 3만 장 데이터셋으로 확장하는 처리 파이프라인도 이때 만들었습니다.

## 3. LLM을 서비스에 붙여 봤습니다

소담소담(창업경진대회 우수상)에서는 AI 파트를 전담해 낙농 도메인 RAG 챗봇의 Query Routing을
설계했고, 럼피스킨병 피부 병변 이미지 진단 모델(테스트 정확도 96.8%)과 착유량·유방염 예측
모델을 학습·비교했습니다. LangGraph 서브그래프를 분리해 조회 로직이 5배로 세분화되는 동안에도
메인 그래프를 그대로 유지했고, 벡터DB 캐시가 한 줄 때문에 무력화돼 있던 문제를 성능 추적 과정에서
찾아 고쳤습니다.

다 맡케팅(KT AIVLE 빅프로젝트 대상)에서는 7인 팀 중 SNS 게시글 관리 축 하나를 FastAPI 에이전트 ·
Spring Boot 서비스 · React 화면의 세 계층에 걸쳐 담당했습니다. 프롬프트 설계부터 API 계약,
화면 상태 관리까지 한 사람이 이어서 책임졌습니다.

## 4. 판단의 근거를 남깁니다

심리학 복수전공에서 설문·통계 설계를 배웠고, 노인의 스마트폰 사용과 사회활동 참여가 인지기능에
미치는 영향을 다룬 논문을 한국산학기술학회에 게재했습니다. 사회조사분석사 2급, ADsP, SQLD로
데이터를 다루는 문법을 자격으로도 갖췄습니다. 어떤 수치가 무엇을 말할 수 있고 없는지를 구분하는
훈련이 실무에서 "이 지표는 아직 근거가 부족하다"고 말할 수 있게 해 줍니다.
